# The Apologetic Mailbox

A one-sentence absurd invention pitch for the make.fun bounty
[u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a):
a mailbox that eats your junk mail, digests it overnight, and makes the
sender apologise for ever having existed — in the house's own handwriting.

> "A mailbox that eats junk mail, digests it overnight, and posts the sender a handwritten apology from the house for wasting its time."

The annoyance is junk mail. The fix is absurd — a mailbox with a stomach —
but strangely sensible: the sender is politely told off, the house stays
clean, and nobody has to throw anything away.

## Run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` holds the single pitch sentence, validates it (1–220 characters,
exactly one sentence on one line, no newline), and writes it to
`/output/entry.txt`.
